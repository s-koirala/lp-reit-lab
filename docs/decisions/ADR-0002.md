# ADR-0002: Deliverable stack — Streamlit screener + Quarto reports + OSM maps

- **Status:** Accepted; **interactive-screener portion superseded by [ADR-0003](ADR-0003.md)** (2026-06-05). The Quarto report, free-OSM-tile map, and DRY shared-engine decisions below remain in force.
- **Date:** 2026-06-05
- **Deciders:** SKIE (user decision at kickoff)
- **Related:** [research memo §7-8](../research_notes/research_market-scoping_2026-06-05.md); [ADR-0003](ADR-0003.md) (supersedes the screener)

## Context
The end consumer is statistically literate but not a CFA/statistician.
Deliverables must be friendly (plots, tables, maps), reproducible, publishable,
and maintainable by a solo researcher. Candidate frameworks: Streamlit, Dash,
Panel, Gradio, Voilà; reporting via Quarto, Evidence.dev, Observable, Jupyter
Book; maps via Folium, pydeck, kepler.gl, Plotly, MapLibre. A UX/stack research
pass (kickoff) compared these on interactivity, reproducibility, Cloudflare-Pages
publishability, and solo-maintainer cost.

## Decision
- **Interactive screener:** **Streamlit** — lowest solo-maintainer cost, Folium/
  Plotly native, deterministic reruns, simple state model.
- **Reproducible reports:** **Quarto** parameterized `.qmd` → HTML/PDF, publishable
  as a static site to **Cloudflare Pages** (matches publishing venues).
- **Maps:** **Folium/Leaflet** (pydeck for large N) on **free OpenStreetMap /
  MapLibre tiles** — explicitly **no Mapbox SaaS lock-in**.
- **Charts/tables:** Plotly (interactive), matplotlib (static/PDF), great-tables.
- **Engine:** one shared Python package (`src/lp_reit_lab`) feeds both the app and
  the reports (DRY).
- **Licenses:** all permissive (Apache-2.0 / BSD-3 / MIT).

## Consequences
- (+) Live exploration (Streamlit) + reproducible publishable reports (Quarto) off
  one shared, unit-tested engine.
- (+) No paid mapping dependency; static reports deploy free to Cloudflare Pages.
- (−) The Streamlit app needs an app server (not fully static); the Quarto side
  covers the static/publishable path.
- (−) Quarto static rendering requires the Quarto CLI (one external install); the
  Streamlit app and the engine need no external tools.

## Alternatives considered
- **Static-only (Quarto/Observable):** fully publishable, zero server, but no live
  server-side filtering — rejected as the primary UX for an interactive screener.
- **Dash:** higher interactivity ceiling, heavier solo-maintenance — rejected for v0.
